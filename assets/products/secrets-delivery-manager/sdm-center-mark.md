## Reference intent

Use the approved Hypershell brand-architecture reference for Secrets Delivery Manager as the semantic guide: a compact shield with a keyhole, expressing secure delivery, governed access and zero-trust-by-design.

## Prompt

```text
Create only the standalone Secrets Delivery Manager center mark on a fully transparent square canvas.

Do not generate the outer Hypershell Family Template ring, spikes, H, wordmark, label, background, border, or any surrounding logo structure.

The symbol consists of:
- one compact shield outline/body
- one centered keyhole shape

COMPOSITION

Create a vertically oriented compact shield with a centered keyhole.

The shield must be perfectly symmetrical left-to-right, optically centered, and readable at small sizes.

Use the approved SDM product reference as the semantic and compositional guide.

SHIELD

The shield uses the same refined Hypershell material language as the accepted masterbrand:
- light-neutral base close to #F1F5F9
- broad, calm planar surfaces
- subtle dimensional depth
- soft controlled highlights
- restrained pink/violet influence on the left
- restrained blue/cyan influence on the right
- premium polished clarity without excessive glow

The shield should feel geometric, secure, minimal and brand-like.

KEYHOLE

Place a compact keyhole exactly in the center of the shield.

The keyhole is light-neutral and clearly legible.
It should have:
- a circular upper lock opening
- a short tapered or straight lower stem
- balanced proportions
- crisp edges

The keyhole should read as an integral security symbol, not as an added decorative object.

MATERIAL AND LIGHTING

Use one coherent neutral studio-lighting environment.

The shield and keyhole share the refined Hypershell visual language:
- controlled highlights
- gentle tonal depth
- restrained reflections
- crisp anti-aliased silhouettes
- no bloom-heavy glow
- no noisy decorative effects

VISUAL CHARACTER

The finished center mark feels:
- secure
- governed
- trustworthy
- technical
- premium
- minimal
- modern
- clearly related to the Hypershell family

OUTPUT

Produce only the SDM center mark with:
- true transparent alpha background
- square canvas
- centered composition
- generous transparent padding
- high resolution
- crisp anti-aliased edges
```
